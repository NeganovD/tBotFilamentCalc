# FilamentCalc для Telegram (Mini App)

Упрощённый калькулятор внутри Telegram: только расчёт, принтеры и настройки (электричество, брак, отходы,
партии). Филамент — одно поле «стоимость катушки за 1 кг» прямо в расчёте. Истории и заказчиков нет.

Сервер не нужен: это статический сайт, а данные лежат в Telegram CloudStorage — на серверах Telegram,
отдельно для каждого пользователя, и видны на всех его устройствах. Ключи: `settings`, `tiers`,
`p_<id>` на каждый принтер. Черновик расчёта — в localStorage, только на этом устройстве.

`js/calc.js` — копия `pwa/js/calc.js` (а та — порт `app/calc.py`). После правок формул скопировать заново.

## Проверка на ПК

```
cd tgapp
..\.venv\Scripts\python -m http.server 8000
```

Открыть http://localhost:8000. Вне Telegram данные пишутся в localStorage браузера.

## Публикация

1. Выложить содержимое `tgapp/` на любой бесплатный HTTPS-хостинг статики: GitHub Pages, Cloudflare Pages, Netlify.
2. В @BotFather: `/newbot` — создать бота.
3. Там же `/mybots` → бот → Bot Settings → Menu Button → указать адрес сайта.
   Или `/newapp` — тогда приложение открывается ссылкой `t.me/<бот>/<имя>`.

Сам бот ничего не делает и нигде не запущен — он нужен только как «вход» в приложение.

## Обновление

Залить новые файлы на хостинг. Telegram кэширует страницу — если изменения не видны, закрыть
приложение и открыть снова (на ПК — правый клик → «Перезагрузить страницу»).
